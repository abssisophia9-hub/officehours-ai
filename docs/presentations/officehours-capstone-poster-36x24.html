OfficeHours AI

AI-Assisted Campus Office-Hours Triage for Finals Week

Sophia Abssi BSc AI and Robotization Graduating Fall 2026 Final Year Capstone Project

Problem Statement

  • Finals week floods faculty with repeated conceptual questions across the office-hours queue
  • Some students hesitate to ask when identity feels exposed
  • TAs reinvent answers under pressure; approved course knowledge rarely compounds

Key Research Objectives

  • Can local Ask Triage (Analyzer → Matcher → Synthesizer) reduce faculty communication overload at intake?
  • Can Quiet ask improve student comfort seeking academic help?
  • Can Matcher + dual-TA staffing cut wait and misroute cost?
  • Can a professor KB gate keep Study Agent answers trustworthy?
  • Can Canvas LTI 1.3 replace manual enrollment for community deploy?

Roles (Per Course)

  • Student — Quiet / Identify me · message / face-to-face / online · status · Rooms · classmate notes · Study Agent · Revision Strategist
  • TA — live queue · claim / help · Help Coach · teaching drafts · shared group meetings
  • Professor — repeated-topic clusters · review insights · KB approve/edit/reject · Canvas materials sync

Key Activities

  • Submit ask → triage + cluster + pending KB draft seeded
  • TA claims → Help Coach (draft / Socratic / rewrite) → reply or shared group meeting
  • Professor approves FAQ → later students retrieve via Study Agent
  • Rooms: Problem / Discussion / Article · Canvas-module chapters · Express Interest
  • One login; membership decides Student / TA / Professor seat per course

Unique Value Proposition

  • One packaged multi-role app — not three disconnected dashboards
  • Role per course — same account can TA CSC 2302 and study elsewhere
  • Quiet ask for privacy + named Rooms for peer help

  • Physical kiosk / barcode / NFC hardware intentionally out of scope
