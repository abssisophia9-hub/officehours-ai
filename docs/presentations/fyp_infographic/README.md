## 60-second pitch

Office hours fail in two directions: staff hear the same conceptual stuck point five times, and quiet students will not put a name on a public channel. OfficeHours is one Canvas-linked desk, not a campus chatbot. A student can file a Quiet ask. Ask Triage labels it, names a TA, and copies a past hint. The TA sees Help Coach only on their screen. The professor stamps the only text the Study Agent may quote. Below similarity 0.42 the agent refuses. The bars on this poster are laboratory scores — development CV and a curated gold file of 80 items — not a live AUI section. Scan the QR for the repo and `./scripts/run_product.sh`.
