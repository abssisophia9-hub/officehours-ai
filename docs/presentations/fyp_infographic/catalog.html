Project Overview

Office hours break two ways: staff hear the same stuck point five times, and quiet students will not put a name on a public channel. OfficeHours is one Canvas-linked desk: Quiet ask, Sharing notes, Stack Overflow–style Rooms, and a professor stamp before any agent may quote.

  • Context / application area: AUI courses at peak demand — students, TAs, and professors.
  • Proposed idea: Four cooperating agents. Ask Triage / Help Coach / Study Agent share MiniLM and a professor stamp. Strategist is the LLM + web-tool agent: it reads how a student asks and learns, then searches YouTube and articles.
  • Expected contribution: Less repeat load, a private way to ask, a classmate notes feed and Rooms, and faculty-controlled AI answers.

Problem Definition & Relevance

Cut repeat load and ask friction without letting a chatbot invent the syllabus.

  • Problem statement / research question: How can campus office hours route asks and still keep professors as the gate on AI answers?
  • Stakeholders / intended users: (1) Students — Quiet ask as a request code, Sharing notes feed, named Rooms, stamped Study Agent. (2) TAs — claimed desk + Help Coach draft. (3) Professors — cluster view, stamp, Canvas modules.
  • Evidence, scope & constraints: (1) Campus agents embed with MiniLM; Study Agent refuses below cosine 0.42. (2) Strategist is the LLM + YouTube/article-tool agent on the learner dossier. (3) Live Canvas blocked on a launch key. (4) No Canvas portal scrape — search tools return structured JSON.

Proposed System / Research Design

Students, TAs, and professors share one web app. The API owns the queue and stamps. Canvas is the campus door.

  • Agent stack: Shared all-MiniLM-L6-v2 for the campus path. Ask Triage = three joblibs. Study Agent = cosine ≥ 0.42 or refuse. Strategist = LLM + YouTube/article tools on the learner dossier (how they ask, style, struggles).

Methodology / Proposed Technical Approach

The innovation is agent integration: four software agents share one encoder and call campus tools. Each agent embeds the ask, acts, and hands the result to the next agent until the job is done.

  • Agent contract: Campus path: MiniLM + queue / roster / stamp. Study Agent copies a stamp or refuses. Strategist is a different contract: an LLM that reads the dossier and calls youtube_search / article_search — it never invents a URL and never writes the syllabus.
  • Shared stack: sentence-transformers encode once → scikit-learn joblibs classify / rank → cosine retrieve. Artifacts: request_classifier.joblib, matcher_classifier.joblib, synthesizer_ranker.joblib.
  • Why this architecture: one MiniLM process in RAM; classify + retrieve in milliseconds on CPU, so thousands of concurrent asks stay on the campus desk. Student-facing text is copied from a stamp (cosine ≥ 0.42) or the agent refuses — it does not generate a new sentence.
  • Data / reproducibility: Synthetic and silver asks; curated gold file; train scripts and joblibs in-repo; three-seat demos.

Ethics, Privacy, Security & Responsible AI

Privacy, security, and responsible AI are in scope for a campus help product.

  • Privacy / human participants: Quiet asks show a request code, not a name, on any classmate surface. Data stays course-scoped by design; logs minimize identifiers.
  • Cybersecurity / legal / standards: Role-based login for access control. Live data travels over HTTPS. No scraping of Canvas content. LTI 1.3 for the campus hand-shake; API tokens follow least privilege.
  • AI use plan: Context engineering — know what a model needs, and what to leave out. Write acceptance criteria a machine can be tested against. Find gaps in the backlog, and defend what you reject. Cite it, validate it, review it, own the errors. Responsible judgment — ethics, citation, validation.
  • AI system risks if applicable: A weak cosine match (< 0.42) must refuse. The stamp is the only write into student-facing agent output.
