# Surveys (historical / optional)

**Capstone decision:** new campus surveys are **not required** for graduation.
Do not treat this folder as a remaining FYP gate. Keep the files as the
**historical instrument pack** (and optional templates if you later want
feedback).

The original study used TAM-style Likert items (PU / PEOU), trust, fairness,
privacy, and wait-time perception, plus a short professor interview.

| File | Role |
| --- | --- |
| [pre_survey.md](pre_survey.md) | Historical student/TA pre instrument |
| [post_survey.md](post_survey.md) | Historical student/TA post instrument |
| [professor_interview.md](professor_interview.md) | Historical instructor interview |
| [unified_product_post_demo_survey.md](unified_product_post_demo_survey.md) | Optional template after a `:5180` demo (includes Rooms) |
| [google_forms_pack.md](google_forms_pack.md) | How those instruments were copied into Google Forms (historical) |

If you still want optional feedback after a demo, you may reuse the markdown
as a Google Form. That is **optional**, not a grading requirement.

See [evaluation_plan.md](../evaluation_plan.md) (historical plan) and
[fyp_evidence.md](../fyp_evidence.md) (what actually counts).
