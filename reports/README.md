# Reports

- `mid_report/` — mid-semester progress report
  - `draft.md` — markdown draft
  - `main.tex` — LaTeX report with demo screenshots
  - `progress_checklist.md`
- `final_report/` — final project report
  - `main.tex` — LaTeX final report with technical + survey evaluation
  - `survey_evaluation_summary.md` / `.json` — generated by `backend/scripts/analyze_survey_responses.py`
- `paper_draft/` — optional publication draft

## Build LaTeX locally

From the repository root (requires `pdflatex`):

```bash
cd reports/mid_report && pdflatex main.tex
cd ../final_report && pdflatex main.tex
```

Screenshot paths in the `.tex` files are relative to each report directory
(`../../demo/screenshots/`).

## Regenerate survey summary

```bash
cd backend
python3 scripts/analyze_survey_responses.py
```

Pilot response CSVs live in `data/survey_responses/`.
